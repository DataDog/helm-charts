# Datadog GPU Benchmark changelog

## 0.1.0

* Initial version: the `datadog-gpu-benchmark` namespace for Datadog GPU Monitoring benchmark runs, with RBAC for the Cluster Agent's Private Action Runner, the runner ServiceAccount, pod overrides, a ResourceQuota, a LimitRange, a NetworkPolicy, an optional PriorityClass and a ValidatingAdmissionPolicy (Kubernetes 1.30+).
